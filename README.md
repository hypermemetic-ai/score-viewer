# Score Viewer

Private application repository for the TUNA score viewer: score library, reading and performance, instrument setup, editable piano fingerings and guided practice on Windows and macOS.

The application is being extracted from [ISO notation](https://github.com/hypermemetic-ai/iso-notation). This initial commit creates the project and records the repair handoff; it does not yet contain the executable source. The extraction will arrive through a reviewed pull request. The existing installed app and releases remain separate from this repository bootstrap.

Notation, score format, editorial tools and engraving belong to ISO notation. Format conversion belongs to [score-converter](https://github.com/hypermemetic-ai/score-converter). Fingering calculation is a separate dependency whose repository extraction is still pending. The interval-learning application belongs to [learning-app](https://github.com/hypermemetic-ai/learning-app).

See [the immediate practice repair handoff](docs/practice-repair-handoff.md).
