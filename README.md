# Pictures: hand moves follow every return

Crops of page 1 of Schumann Op. 68 No. 13, engraved from ISO's public MusicXML source (`schumann-op68-no13.musicxml`), Jankó four-row layout. All crops are at the same scale. The edit: bar 11's two pickup sixteenths (B3, C#4) moved to the left hand.

- `bar11-edit.png`: the edit at bar 11. It looks the same on main and in this PR.
- `bar1-main.png`: bar 1's opening pickup on main. It stays in the right hand.
- `bar1-this-pr.png`: bar 1's opening pickup in this PR. It takes the left hand, as at bar 11.
