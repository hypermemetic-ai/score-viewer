# Proposal

## Why

The user selected a clearer TAB vocabulary: fret numbers carry pitch, detached headless duration cues sit below the strings, black ink gives a consistent reading surface, and rests belong on the TAB staff. Adopting this treatment needs a new reproducible source recipe and a safe way to select an additive style edition without reinterpreting historical archives or losing manual practice progress.

## What Changes

- Add one reviewed production TAB engine with upward free tips at a common band top and connecting rails/hook ends below, preserving existing TAB-v1 public defaults and literal replay.
- Bind black duration paint, short half/normal quarter/absent whole markers, source-owned hook/rail geometry, source-written dots/tuplets and staff-centered source rests to that recipe and complete geometry audits.
- Dispatch the existing dual-reading descriptor through its per-view engine identity in actual Worker and independent receiving/cold paths, with no persisted admission certificate or DOM-based renderer substitute.
- Group complete local homogeneous beamable tuplets using the existing source layout's complete expression proof; retain explicit beams, rests, partial/mixed groups and contiguous inferred-group remnants truthfully.
- Preserve canonical source bytes, ISO output, owners, written/elapsed clocks, string/fret facts, authored beam facts/ISO topology and presentation-independent manual/reference journals.
- Add an explicit admitted same-source retained-style edition install/selection path that preserves old archives, library identity and personal pointers; keep generic conflicting imports refused.
- Keep product controls compact: fresh imports select the accepted renderer internally, and retained editions use existing applicable flows without a new TAB style picker, renderer-version labels or rhythm commentary in Options.
- Validate normal-scale full-page and joined notation, keyboard/manual behavior, cancellation, preservation and later ordinary paired native delivery separately.
- Track the existing written-versus-elapsed half-triplet ISO linter issue as an independently owned source dependency, with a concrete disposition before claiming its support; do not weaken it for this style.

## Capabilities

### New Capabilities

- `detached-tab-presentations`: Versioned source-owned detached TAB vocabulary, exact historical/Worker/cold replay, source and ISO compatibility, and presentation-independent manual state.
- `retained-reading-editions`: Explicit same-source style edition installation and selection with additive archive retention, guarded managed-library publication and personal-state preservation.

### Modified Capabilities

None. Existing `practice-package`, `practice-passage-display` and `score-viewer-delivery` requirements remain authoritative. The implemented `support-fretted-manual-practice` change's source/progress/intake contracts are preserved; this change adds style-version and edition behavior without reopening its instrument or physical-assessment scope.
