## Risks / Trade-offs

- [Rehashed but false new-style archive] → Exact source engine replay and complete per-view comparisons in every realm; no persistent certificate.
- [Duration authority inferred from elapsed/placed ticks] → Retained written values, deliberate PR352 integration and positive/malformed/historical-receipt witnesses.
- [Simplification erases weighted/grouped meaning] → Source-proven isolation, exact ordinary equivalence and explicit/complete/weighted/mixed/ambiguous/fractional negative controls; audit canonical facts separately.
- [New ISO paint silently replaces an old recipe] → Explicit known versioned pair, full old/new replay and source-owned compatible-difference proof; keep the old fixed ISO branch literal.
- [Continuity overmerges rhythmic meaning] → Certified local tuplet overlap only, scoped bracket/3, explicit syntax/boundary exclusions and measure 163 plus negative fallback controls.
- [Augmented whole has no genuine base] → Keep the visual issue open; no fret-attached/whole-symbol exception or final acceptance without a reviewed source treatment.
- [New primitive inventory omits detached or staff-rest ink] → Actual per-piece/cardinality, foreign-ink and full joined-window controls.
- [Manual progress forks by visual engine] → Equal existing musical/reference digests and byte-preserved journals; geometry cache invalidation separately.
- [Changed source disguised as style] → Exact old/new admitted source/scope/ISO comparison and generic import conflict preserved.
- [Cancellation or lost acknowledgement changes selection unexpectedly] → Single operation ownership through activation, exact library snapshot checks and honest committed/unknown outcomes.
- [Cold synchronous residue still stalls] → Actual import/cold/warm heartbeat and cancellation measurements; the visual profile is not a responsiveness guarantee.
