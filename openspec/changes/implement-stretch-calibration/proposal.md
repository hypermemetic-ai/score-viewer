# Proposal

## Why
The current calibration collects alternating effort under a flat schematic, while the accepted calculator handoff requires static stretch, relative reach and conditional triple boundaries. The user has authorized completing the new flow with the reviewed interface and placement decisions.

## What Changes
- Adopt the root-exported stretch/curl contract and accepted sloping Jankó geometry; reconcile all-pair same-row depressed alignment and conservative reachable sweep baselines upstream.
- Collect four relative readings, ten adaptive pair sweeps and ten conditional triple slots per measured hand/location, with six stretch grades and explicit stopping/omissions.
- Provide a freely rotatable, zoomable physical visualizer with anchored percentage windows; percentage stays the default and direct millimeters/primary selection remain available.
- Retain historical calibration bytes/protocols and scores, settings, personal fingers and practice progress without numerical migration.
- Add separate optional curl evidence, strict validation, append-only corrections, keyboard-only input and complete exports.

## Capabilities

### New Capabilities
- `effective-curl-refinement`: Optional endpoint-specific personal curl evidence and honest supplied assumptions.

### Modified Capabilities
- `exploratory-calibration`: New static stretch collection, physical geometry, adaptive queue, triples, durable input and review.
- `fingertip-calibration`: Signed relative readings in one mapped forward frame, per-hand identity and model-backed presentation.

## Impact
Viewer calibration modules and managed-file allowlists, pinned calculator root package, accepted upstream collection contract, browser/native frontend delivery. Calculation engines, musical score data, authentication and provider/workflow configuration remain outside this repair.
