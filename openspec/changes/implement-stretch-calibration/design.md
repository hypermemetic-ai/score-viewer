# Design

## Context
See proposal.md. Existing effort/fingertip protocols and installed evidence remain historical. The updated package exports wire contracts and a regularized Jankó seed but no adaptive collector or validator. The user explicitly authorizes implementation with routine design decisions resolved from prior directional feedback.

## Goals / Non-Goals
**Goals:** Collect exportable contract-compatible personal evidence with faithful physical targets, durable operations and usable keyboard navigation.
**Non-Goals:** Fit anatomical lengths/costs, activate new calculated fingers, infer movement/fatigue laws, or overwrite historical evidence. Conventional keyboards keep historical export; the new Jankó-specific profile is explicitly selected.

## Decisions
- Upgrade the reviewed root package, adding an upstream same-row policy so thumbs are truthfully represented. Retain historical policy values and handlers. A viewer-owned versioned archive contains exact stretch wire sessions; raw numeric drafts are retained in documented entry notes.
- Use strict runtime validation, canonical snapshot hashing and append-only effective-ledger derivation. Triple structural validity references original grade-3 entries; current applicability is derived separately. Correcting contacts creates new targets rather than mutating prior identities.
- Every pair uses a declared common row (1 or 2), depressed contacts and region evidence. Initial separation is the smallest even step span meeting the absolute signed reach difference, minimum two steps; setup permits adjustment to a reachable baseline. The unknown shorter tail is never graded unavailable.
- Triple slots declare all admitted playable surfaces as their search scope, then choose outward contacts relative to the actual source pair. Default source is the widest effective grade-3 report; the player can choose another actual report. Region anchors retain a shared realization identity and require physical reproduction.
- Percentage windows use a common declared depth interval for both flat-finger contacts, preserve both fractions/reference and frame, and normalize signed second-minus-first. Direct millimeters remains independent. Orbit projection never changes world endpoints.
- Implement code-native interactive 3D projection from complete extruded body profiles, playable terraces and pressed transforms. Preserve camera across trial updates; keyboard rotation is local to a focused visualizer.
- Reuse shared navigation/footer and practice-browser review styling. No local global-notation or MIDI controls. Optional curl editor is a separate companion document with no assumed default sizes.

## Risks / Trade-offs
- The nominal pressed transform is estimated → preserve its status and avoid claims of measured contact coordinates.
- Baseline heuristics may be imperfect → the player adjusts the starting arrangement before any outward rating.
- Broad triple surface scope can reach a keyboard edge → distinguish coverage-edge, usable-limit, unavailable and omissions.
- Invalid historical/new bytes → retain originals and forbid replacement, including export envelopes.

## Migration Plan
Add new exact managed filenames, keep every old file untouched, verify all contract and UI paths, land reviewed source and deliver a frozen native carrier through the established lane. Preserve app/data/shortcut additively during activation.
