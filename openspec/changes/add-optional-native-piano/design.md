## Audio and preferences

The existing `practice_audio::State` owns one shared native output. `piano_audio_configure` takes enabled, volume, shared device and latency tier; `piano_audio_status` returns actual ready/running/rate/period/buffer/RAW/fallback/error state. The engine loads/drops off the callback. Native MIDI reaches the engine before WebView delivery; existing assessment, musical sustain, input bindings, count-ins and practice cues remain independent. Stop practice cues without dropping an enabled piano. Window focus/minimization does not gate or silence native piano; genuine disconnect/reset/queue overflow clears voices safely.

Piano preferences are additive in `preferences.json`: version 1, enabled false, volume 0.7, latency tier 0 defaults. Preserve saved choices and unrelated fields. A missing/unadmitted bank always makes the effective enabled state false; installation does not automatically enable sound or connect MIDI. Volume is 0–1. A compact four-choice Latency setting requests host tiers 0–3 with monotonic minimum/at-least-5-ms/at-least-10-ms/at-least-device-default-and-10-ms periods; actual legal periods can coincide. Volume reuses the accepted shared numeric spinbox, entered typing/arrow editing, stacked mouse chevrons and exact untouched/cancelled saved values. The discrete latency control has one browse stop, four rigid choices and entered arrow editing; ordinary browsing does not change sound. Its concise help explains that higher settings can reduce crackles, pops or dropouts but increase delay, with unchanged piano sound quality. Browsing arrows navigate Options; only entered control editing adjusts values. On Mac the four-choice control deliberately adjusts the selected output’s shared HAL I/O buffer, after checking its current value, legal range and settable status. Stop the stream before a change and restore the previous value on disable, output change, reconfiguration and normal exit only when the buffer is still the value owned by this host. This approved shared-buffer adjustment is the only device-setting exception: keep sample rate, format, default output and drivers unchanged. Report actual queried buffer and restoration failures. Help explains that other apps using the output share the temporary setting. Match actual admitted output mix format; do not promise 44.1 kHz or measured physical latency. A tiny Sound feels delayed? affordance opens compact owned help with short Connection/Latency and relevant system guidance, without default rate/period diagnostics or RAW jargon, and conditional Windows guidance linked to Microsoft's primary documentation with the driver tradeoff. No automatic driver change or permanent checklist. Escape closes only help and restores its opener's focus.
