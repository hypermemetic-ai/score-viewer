# Design

## Context
The active form starts with empty endpoints, centre, body offset and seating text. Instrument preferences declare keyboard layout, not verified physical limits. Existing calculator provenance requires finite coordinates and a nonempty reference; these can describe a nominal protocol frame honestly.

## Goals / Non-Goals
Begin measurements from a hand choice with ordinary keyboard controls. Preserve the accepted models, recorded observations, existing calculator package and pair/triple evidence semantics. Do not infer actual seating, anatomical body position or hardware endpoints.

## Decisions
- Supply row 1, central key 61 and a symmetric central working window 37–85 from the accepted profile lattice. This is operational coverage, explicitly described in geometry/reference text as unverified physical extent.
- Record nominal origin 0 and explicit unmeasured body/seating reference text. Starting the displayed hand test selects the proposed central location; it does not measure body pose. Hash the qualified geometry snapshot normally.
- New hand collection opens two direct hand choices with R/L shortcuts and Enter on the focused choice; the first reading receives numeric focus. Keep the existing home shortcut and navigation positions.
- Remove active legacy thumb–pinky entry routes. Historical exports and score calculation state remain intact.
- Verify fresh start through a saved reading using the real production keyboard path; repair any visible-primary-action mismatch that prevents Enter from progressing, while retaining contact readiness for pair/triple ratings.
- Recover the original length-difference protocol from calculator conversation item `02099bfb-c768-4113-9465-bb6e1c5b3f35` and accepted viewer artwork. This is separate from span/stretch measurement: straight, flat fingers point along the keys. Thumb/index use canonical pitches 61/64 on rows 1/2; other adjacent pairs use 60/62 on row 2. Left-hand pitches reflect through `124 - pitch`.
- Anchor each 0% line to the neighboring opposite-parity next level and 100% to the finger's own next-level wall. On the current profile the thumb window is 34–59.8 mm and lower-main windows are 66–93.75 mm. Preserve profile solids and resting contact; do not import the span test's depression or fingertip-line conditions.
- Convert each local percentage to physical forward depth, then normalize both depths into one declared common wire axis. Retain original decimal text, primary finger and both local window definitions in notes. Two 100% readings on staggered thumb/index walls have different physical depths.

## Risks / Trade-offs
A working-window edge is not proof of a hardware edge: label it as test-window coverage and keep untested contacts unknown. Explicit nominal metadata avoids fabricated physical setup evidence. Preserve raw setup and geometry for already-started collections during the additive native update.
