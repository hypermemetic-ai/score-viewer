# Proposal

## Why

Guitar Pro users need to read and manually practise the same Bass or Guitar part in ISO notation or tablature. The current seatless reading path supplies ISO pages but excludes practice, while the existing practice planner requires piano pitches, hands and seats.

## What Changes

- Import supported Guitar Pro through the converter's reviewed, bounded public adapter and retain original source/provenance without widening format claims.
- Offer Bass and Guitar instrument profiles and ISO / TAB notation using genuine selected source parts, tuning and written-component string/fret facts.
- Admit independently prepared ISO and TAB pages, musical appearances and relations against one canonical source without piano contacts or hand assignments.
- Add manual musical practice independent of piano assessment, reusing passage selection, musical count-in/repeats, speed policy, Free view and reversible Done.
- Share musical progress across notation choices, separate distinct source parts, and retain legacy piano storage and assessment unchanged.
- Provide explicit previous/next overlapping four-measure windows during manual playback without stopping the musical clock, hiding played notes or sliding notation. Return to the initial window only at an explicit repeat count-in.

## Capabilities

### New Capabilities

- `fretted-score-presentations`: Source-faithful Bass/Guitar profiles, retained tuning/component positions, bounded GP intake and independent ISO/TAB presentation admission and selection.
- `manual-instrument-practice`: Neutral musical planning, explicit manual assessment, shared evidence and keyboard-readable passage windows.

### Modified Capabilities

None. Existing piano passage-display, refill, package and delivery requirements remain authoritative.

## Impact

Viewer capabilities, practice planning/session/context, passage geometry adapters, library progress, saved view/progress, reader Instrument/Notation controls and shared Options. The converter public runtime adapter and ISO neutral source/TAB contracts are coordinated dependencies owned in their respective repositories. This change does not implement guitar audio-input assessment, modify piano audio, migrate existing piano journals, or activate a native release. Existing v1/v2/v3 archives retain literal admission and drawing authority; new presentation contracts dispatch explicitly.
