# Stretch calibration

Calibrate under Options → Fingerings opens the contract-based collection. The new collection uses the accepted regularized RR/Jankó profile and the calculator's root-exported `stretch-calibration-protocol-v1` / `stretch-calibration-session-v1` wire format. Conventional instrument selection identifies that a new Jankó collection requires selecting Jankó; historical evidence remains exportable. No conventional geometry is fabricated from the Jankó seed.

Start a New hand collection with N, then choose Right hand with R or Left hand with L; Enter starts the focused hand. The first fingertip reading opens immediately with numeric focus. Each hand keeps a separate collection. No keyboard endpoints, row, central key, body offset or seating description is required.

The app proposes a nominal central protocol frame on row 1 with MIDI key 61 and a symmetric test window 37–85. Retained geometry and provenance explicitly state that body/seating position and physical keyboard endpoints were not measured. The numeric origin is a coordinate convention. A test-window edge records limited collection coverage, not a verified hardware endpoint or an unavailable untested contact. Existing collections retain their original setup.

Progress counts four relative fingertip readings, ten adaptive pair sweeps and ten conditional triple slots, with omissions and actual judgments separately visible. There is no fixed remaining pair-judgment count. The old thumb–pinky collection editor is absent from current entry and Options; historical evidence remains in Export all evidence.

Percentage is the default reach method; direct millimeters and editable primary-finger selection remain available. Both percentages refer to one physical forward window and retain its endpoints, fractions and reference frame. Signed second-minus-first differences sum across adjacent readings. Negative entries are accepted. These are relative effective reaches, never inferred bone lengths. Raw entries and their selected method/reference are retained as documented JSON in entry notes. Camera rotation changes only projection and never changes the measurement window.

Pair tests use same-parity keys on one physical row, including thumb and pinky, with both keys depressed and flat fingertips lined up parallel to the keyboard. The hand and arm can be repositioned between static contacts; no trill or fixed-wrist requirement remains. A conservative starting suggestion rounds the absolute measured reach difference to the next available 27.5 mm same-parity spacing, without an added margin. The player establishes a comfortably reachable baseline before the rated outward sweep. Smaller skipped candidates remain unknown.

Six ordinal stretch ratings range from 0 (none/barely detectable) to 5 (unavailable). Every prepared contact accepts the player's actual answer, including an initial 5. An unavailable starting contact is retained as evidence and allows another starting contact; it does not invent a reachable baseline or end the outward sweep. Grade 4 is reachable. Mark my maximum is explicit after a reachable report; an unavailable result outward of an actual earlier reachable report ends a sweep with both references. Operator stop and coverage edge are distinct terminals. Held computer keys, OS repeats, simultaneous commands and pending saves cannot grade future targets. Calibration admits no MIDI rating commands.

The pair screen shows the physical contacts and static-stretch instructions without ledger coordinates or span bookkeeping. Left/right moves between adjacent finger pairs, leaving unanswered pairs unmeasured and retaining all earlier reports. Model, picker and editable controls own their input before measurement navigation. Keyboard rotation is an explicit model mode: arrows rotate, +/− zoom, Home resets and Escape leaves the mode. The complete rating area is kept clear of the footer; compact camera controls preserve the existing physical model and measurement windows.

Each triple uses an actual effective grade-3 report from its first two fingers, with the widest suggested initially. Reproduce the same contact points and keep both anchors depressed; move the remaining finger outward within the declared playable-surface search window. Regions retain unknown but shared realization identities. Save the last usable contact or an explicit coverage edge; a genuinely tested absence of usable outward contact retains attempted contacts. Missing grade-3 anchors and deliberate skips remain explicit omissions. No overall triple grade is manufactured from its endpoint.

Review uses grouped practice-selector navigation. Replacements and withdrawals append to the ledger. A triple keeps its original source link when that source is revised/withdrawn and shows that its basis needs review. Resume requires reproducing current contacts. Save failures preserve accepted evidence and drafts. Invalid bytes are read-only and exportable.

Optional curl readings are separate evidence for fingers 2–5, outside core progress. The editor accepts positive personal ruler measurements with either the effective bent-section or visible PIP-crease endpoint convention and nullable uncertainty. Supplied assumptions remain labeled estimates; no default is fabricated from relative reach. Assumptions, personal entries and retractions retain their original provenance and ledger order.

`stretch-calibration-v1.json` holds the versioned viewer archive of exact wire sessions. `effective-curl-refinements-v1.json` holds one exact companion document or a multi-player/hand wrapper. Export includes complete ledgers and original historical calibration bytes with hashes and base64 encoding. Older effort, pilot, fingertip, span and musical data are retained without numerical conversion. New evidence does not activate a fitted hand model or change calculated/personal fingerings.
