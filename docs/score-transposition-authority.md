# Score transposition authority

Viewer transposition is an additive derivation, not a mutation of the imported
score. `viewer-score-transposition-v1` retains one exact, independently admitted
untransposed archive at `transposition/original.isoscore`. A retained baseline
with a transposition envelope is refused before nested admission. Its historical
raw rendering recipe must independently reproduce the literal baseline before
its options/tokens can be adopted; an already cold-replayed calculated baseline
retains its existing source-owned factory authority. This member
is the portable exact 0 restoration archive; the collection installer preserves
its original sidecar and achievement journals separately.

The ordinary source-score member is the deterministic effective source. Its
source SHA, layer source identity and rendering recipe bind the effective
pitches through existing strict checks. The envelope separately binds the root
source SHA, baseline archive SHA/layout, integer offset, effective source SHA
and originating selected-request archive SHA. Unchanged same-offset/map
generation retains this admitted authority so the physical exercise identity
stays stable. A separate transient worker result binds the current requested
archive SHA; the receiver checks its independently retained request snapshot
before admitting a completion. That snapshot also supplies the expected guarded
map/context and complete replay rather than trusting a returned worker claim.
No field is added to ISO's strictly tempo-only calculation context.

The complete sorted owner hand map is explicit **Viewer selection authority**,
guarded by original owner ID, pitch, onset and duration. The reader verifies it
equals the independently admitted selected request edition. Cold import admits
the untransposed baseline and all original owner guards, reconstructs the
effective source, and independently checks the new layer, complete engraving,
recipe, coverage and annotation receipt. It does not establish historical user
intent, authored hand authority, anatomical suitability or continuous movement.
Authored/editorial hand requirements continue to constrain physical planning.

New transposed calculations use preparation V4 and calculated-hand receipt V3.
Their context binds the complete transposition envelope as well as the existing
pinned annotation-ink policy. Historical preparation V1/V2/V3 and receipt V1/V2
retain their literal meaning and never acquire a transposition exemption.

Every genuinely new pitch preparation uses the shared calculated-hand renderer
and physical assignment calculator with the selected hands retained. Same-hand
fixed-page reuse is disabled. Each newly prepared derived archive carries its
requested layout; prior archives remain retained by the installer. A missing
zero-layout companion is prepared additively through ordinary untransposed
readiness before deriving that layout, preserving existing original pages.

Absolute note, repeat-tie, pitched grace, supported occurrence-override and
source-hand-guard pitches shift together, without clipping or octave folding.
Relative/reading source projections and unfamiliar pitch-bearing fields refuse.
Timing, owner IDs, source relation identities and non-pitch provenance remain
unchanged. Physical pitches are ISO coordinates 9–96, corresponding to A0–C8.

The selected calculation reference is retained and rebound to the effective
source hash; ISO's source-reference conflict rules remain in force. Reference
MIDI is an exact original-source attachment, independently compared against the
retained baseline. It is not transposed playback: the current viewer only admits
that attachment. Live piano MIDI passthrough still sounds incoming physical keys.

New pitch editions do not inherit old pitch/contact corrections or achievements.
The request service returns no migrated personal journal for a changed offset.
Retained-offset reuse requires exact root baseline, layout, guarded hand map,
retained-hand policy and reference context compatibility, rather than trusting
an offset or an internally consistent archive alone.
