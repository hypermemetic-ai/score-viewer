# Personal hand and finger choices

Personal choices live in the existing source/layout-bound journal; pressing L/R does not rewrite the imported archive, change its admitted hand digest, or select a new practice storage file. The optional `personal-owner-assignments-v1` overlay records each source owner, its exact pitch/start/duration guard, the original performing hand/finger and the personal values. Old journals without this field remain valid. Legacy finger corrections, calculated layers, undo records and history remain separate and retain their original meaning.

The effective assignment resolver supplies one complete owner map. A hand choice retains the current personal finger. Duplicate written heads and continuation appearances refer to the same physical/source choice; independent recurrences are not changed. Stale guards, corrupt values and conflicting physical aliases refuse journal admission rather than erase choices or invent new state. Restoring a choice removes its overlay and reveals the original assignment; restoring all retains the overlay in `undoAssignments` for recovery.

Practice planning uses effective hands while keeping the immutable archive revision and storage identity. An exercise's original source and played range own its claim identity. Personal hand and finger edits preserve measured and self-reported progress, including joined exercises; they never reset completion. Historical records retain their original assignment provenance without rewriting the evidence. Library summaries read the same personal journal and preserve credit after reopening.

The semantic `personalPracticePackage` view is exclusively for planning. It must never be exported, admitted as a calculated edition, or used as proof that notation was regenerated. The live renderer separately projects the guarded map through shared notation rules. Explicit calculation receives personal choices as source-guarded operator constraints; immutable source/calculated provenance remains available independently of those requests. When a requested calculation materializes a new immutable edition, each personal choice must match its admitted assignment. The new sidecar rebinds those active choices to that edition; superseded legacy correction and original-overlay facts remain in the retained prior edition and its original journal, rather than becoming contradictory active corrections on new-hand pages.

Accepted in-memory intent and durable state are distinct. The editor's ordered persistence controller must retain pending snapshots on failure and visibly report the failure; neither delayed writes nor stale projections may redirect an accepted edit to a later selected note. Do not clear a damaged/missing declared journal or substitute another edition's journal. Recovery keeps its bytes, immutable archive and last durable snapshot available for inspection.

Optional navigation metadata records the selected source owners, written bar, source action, continuation status and alias ordinal. The personal journal keeps its existing identity. Each queued edit resolves its own navigation against its own notation projection before saving; later page changes save only navigation over the latest durable choices. An older projection cannot move a player who navigated again. On reopening, source aliases recover the page and selection after projection, including a projected page beyond the imported page count; source-empty pages use a bounded numeric fallback. Invalid optional navigation is dropped without losing hand/finger choices or history. Calculated editions carry validated navigation with the existing source-bound personal transfer.

The navigation regressions execute the production handlers and state validator with controlled projection geometry, including a five-page base becoming six pages, delayed Exit/Library saves, reversed projection completion and held continuations. These tests establish persistence and race behavior; they do not establish an actual engraving change or visual acceptance.

In Edit, plain L/R choose the selected note’s left/right performing hand. Selection and its current finger stay in place; a finger digit retains the usual advance to the next note. Choices repaint without waiting for disk. A failed save keeps a persistent recovery message with Retry saving and Keep a recovery copy; pending source-bound choices remain available until saving succeeds. Current practice uses the current choices while earned progress remains intact.
