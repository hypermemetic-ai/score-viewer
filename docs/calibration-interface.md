## Global notation and calibration entry

The left-aligned Calibrate command opens calibration from Options → Fingerings and returns to that section on Back. The former Hands section is replaced by the global Notation section. ISO is currently the available notation system; Traditional is visibly unavailable until regular sheet music is supported. Calibration Options reflects the same global restriction, while physical key colors remain independent.

The global setting uses the additive `notationSystem` preference. Existing `calibrationNoteNames` bytes remain retained with other preferences; they do not enable an unavailable global notation system. No saved reading, effort grade, score or fingering is converted by this interface change. Native delivery of an earlier revision is separate from this source preview.

Calibration Options uses the same system font, normal-weight title and inset panel treatment as rating review. It shares global Options navigation: arrows browse controls without changing values, Enter/keypad Enter/Space opens a choice, and arrows browse enabled choices. Enter confirms; Escape cancels an open choice before leaving the page. Tab/Shift+Tab stay within the dialog. The notation selector receives initial focus; later visits restore the last control. Held activation keys do not reopen or commit choices, and disabled Traditional remains unavailable. Its notation, key-color, span and input controls retain their saved values and return route. The device panel remains connected and hidden on other calibration pages so asynchronous input discovery can finish; opening Options moves the same mounted controls into its body. Disposing a shared Options navigator removes its generated selector buttons/listeners and restores the native selectors, so persistent device fields can be prepared under the next owner.

## Calibration menu

Back occupies the bottom left and Options the bottom right of the active screen or dialog throughout the application. Existing task controls remain between them. Library has only Options; Options pages have only Back. Reader navigation remains in its hideable toolbar, without reducing the score viewport. Calibration uses a persistent footer; fingertip content scrolls independently of its footer. A focused navigation button owns Enter, keypad Enter and Space, so activating Back or Options cannot also begin a trial, save a reading or mark practice Done.

Scrolling never displays a stock scrollbar. The shared application/dialog styling hides native bars while retaining wheel, touch and keyboard scrolling. The existing thin Options position marker remains available for overflowing settings panels.

The main menu uses a compact panel with aligned command rows and a labeled effort count. Its title, controls, counts and keyboard hints use the application's system font. Continue has initial focus. Arrow keys select enabled commands, Enter opens the selected command, and F, R, E and O directly open fingertip readings, rating review, export and Options. Disabled commands remain unavailable by shortcut. Menu navigation uses the shared Options navigator only on the main page; measurement selectors and rating input retain their existing keyboard behavior. Focus returns to the chosen menu command when leaving a subpage, including after starting or resuming effort work.

## Placement setup

The placement instruction asks the player to choose the most comfortable position anywhere on the highlighted keys. Highlights fill the full displayed face of the assigned Jankó level and stop at its boundary; the other physical copy stays unhighlighted. Conventional targets include their full front and rear outlines with black-key cutouts. Target bodies remain visible even at the widest tested distance. This display change preserves sampled key identities and the nominal geometry recorded in existing evidence.

On placement setup, the illustration precedes three separate instruction points in a centered block capped at 900px, with left-aligned text, thin dash markers and equal font size and weight. All text, including finger indicators, uses the system font. This layout revision leaves the current measurement task unchanged. New setup acknowledgments retain the displayed comfortable-position wording. Exact earlier center/depth instructions are admitted as historical text without rewriting them or their associated reports.

The effort-rating page uses the system font throughout. Its two left-aligned instruction points use thin dash markers and sit to the right of the enlarged illustration in a centered block. The question and ratings sit lower, in a centered 900px block below. Compact rating labels and descriptions fit completely at 1280×720; at narrower widths the descriptions stack and remain reachable through scrolling above the persistent footer. The five ratings, their wording, shortcuts and measurement protocol are unchanged.

Change a rating uses the practice section selector's two-column row styling, current-selection treatment, and shared contextual scrolling. Groups occupy the left column; the selected group's recorded conditions and ratings occupy the right. Up/Down moves within a column, Right enters its remembered rating, Left returns to groups, and Enter (including keypad Enter) or Space enters a group or opens a rating. Tab reaches the shared Back/Options footer. Each group retains its selected rating and scroll position after Options or reopening review. Held activation keys do not reopen a condition, and busy/read-only controls remain disabled. Selecting a rating retains the existing route back to that trial's placement setup.

Grouping is a presentation projection supplied through generic group/row identities and labels. The current batch adapter groups by finger combination and labels each recorded condition with its distance, actual finger/note contacts and key levels. It admits only retained measured trials and uses their original trial identities. It changes no plan, protocol, saved observation, exclusion, or measurement ordering; future batches can replace the adapter without changing the browser navigation.
