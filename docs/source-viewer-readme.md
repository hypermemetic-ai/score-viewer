# ISO Score Viewer

Tauri2 native shell and shared TypeScript offline reader, with Windows and a private Mac build. See [`../docs/reference/score-viewer-windows.md`](../docs/reference/score-viewer-windows.md) for launch, controls, personal choices, Stream Deck setup and rollback. See [`../docs/reference/score-viewer-package-v1.md`](../docs/reference/score-viewer-package-v1.md) for the passive semantic/vector package.

Import `.tuna` scores or Guitar Pro files. Press **H** to show the reading toolbar, then choose **Share score** (also in Options) to save the installed score as one `.tuna` file. Its original fixed pages, declared keyboard presentations and reference MIDI travel together; your finger corrections, histories and device settings stay local. Browser mode starts a download; the desktop save dialog can be cancelled. Reference MIDI is retained for checking, without playback or changes to written notation. See [publication inputs and format](../docs/reference/tuna-score-package.md).

`npm install`, `npm run build`, `npm test`, `npm run tauri -- build`. The calculator loads in a worker only on request; the normal reader bundle carries no research traces. Musical pitch/source identity remains separate from displayed finger numbers. Import dialogs and data writes are bounded native commands; there is no arbitrary filesystem or shell bridge.

Local feedback stays local. Finger proposals/physical rows are not certified anatomy or global optimum. Windows acceptance and physical pedal acceptance are separate. Later platform targets: Linux, iPad and Android tablets.

For absent preferences, F (or the assigned pedal/control) toggles small fingers beyond their stems or beams while retaining pitches; fresh scores start with fingers hidden. Options → Expert settings contains independent Toggle / Hold and Replace note numbers controls. Valid saved Hold preferences remain Hold. Replacement uses the original black full-size number seats. Transient holds are never saved; focus loss, modal/settings and session changes clear them.

E resumes the revision-scoped last selected physical contact, revealing fingers without holding a pedal. Arrows or Tab/Shift+Tab move; plain1–5 autosaves directly and advances to the next contact. Enter retains the optional editor. Escape cancels a modal first, then leaves selection; H reaches the toolbar and its ordinary Tab order. In selection, Toggle uses distinct display-key/control/pedal presses to alternate fingers and original pitches, with a separate transient editing view. Hold shows original pitches until release, then restores fingers. Both retain the selection marker and saved ordinary-reading visibility. Blur clears comparison and retains the selected contact. Personal and calculated fingers use identical presentation and retain baseline/row provenance.

Keys & pedal → MIDI pedal can explicitly connect a unique desktop MIDI input and learn an unused controller by pressing and releasing it. The native midir adapter (WinMM on Windows, CoreMIDI on Mac) is passive input only, with no startup auto-open, MIDI output or route changes. Sustain CC64 is excluded. Conventional64/32 hysteresis thresholds are fixed thresholds. Keyboard/host-simulation checks do not certify actual concurrent Windows reception or musical pedal effects. See [MIDI route evidence](../docs/reference/score-viewer-midi-route.md).

Importing an identical source with verified header-only cleanup offers Refresh header or Keep current. The previous archive remains restorable, with all personal sidecars/calculated versions intact. The currently installed sole No.14 entry contains corrected44–48 hands and a compatible complete finger layer. See [current setup](../docs/reference/score-viewer-current-no14-setup.md) and [editing update](../docs/reference/score-viewer-editing-native-handoff.md); older follow-up package identities remain historical evidence.

Annotations use the embedded URW Gothic font at 68% of the pitch size and muted blue-gray `#56788f`. Each finger centers beyond its source-linked rhythm carrier, above upward stems or below downward ones, with a 40%-em gap beyond its beam, flag or duration-ring envelope. Shared chord stems carry a vertical stack with higher pitches above lower pitches. The reserved bounds include every digit 1–5; edits and Calculated/Yours switching do not move labels. Rotation and score scaling transform the same frozen page and annotations together. Dense passages can still crowd other musical ink; annotations never move notes, change page breaks, hide fingers or enlarge practice crops. Choose replacement in Expert settings for a cleaner dense display. The existing all-five frozen-seat safeguard applies only to replacement; source/layer validation applies to both.

Guided practice, preparation previews and Performance share this presentation. Practice annotations inherit original note-owner visibility and crop bounds. Contact/error feedback stays on the original note; inspection keeps its existing clock/audio/grading/progress lifecycle. MIDI contact feedback does not verify fingers.

Keyboard selects Conventional piano or Jankó four-row independently of the fingering display controls. A clean installation starts with conventional piano; an existing installation whose saved No. 14 used Jankó retains Jankó until changed explicitly. A linked score package keeps both presentations in one library entry. Switching keeps the written measure in view, while personal fingers, calculated history, practice progress and performance records remain separate for each source, keyboard, profile and hand division. Original legacy files remain available and are never migrated in place.

The supplied No.14 package includes both compatible presentations and immutable original source data. Generation for its declared recipe calculates hands and fingers together, independently replays the repeated performance, and re-engraves those hands with the bundled real engine. Existing pages and personal choices remain available during calculation; cancellation or installation failure retains the active package. A successful installation stages a new archive and a fresh saved-state version before changing the library pointer. Saved-state versions support ordinary subsequent editing. Packages without a matching recipe remain readable; generation requires a supported prepared package.

The conventional calculator uses an unmeasured standard profile, not saved Jankó choices. Its output is an editorial recommendation within a bounded physical-contact search. It is not a claim of globally optimal or individualized anatomical fingering. Mac setup and private-build installation are described in [the Mac guide](../docs/reference/score-viewer-macos-install.md). MIDI input, audio outputs and physical pedals require separate native-device verification.

Practice groups adjacent learned sections under one compact joined range; its own percentage remains independent. Right enters the component list and Left returns. A selected original leaf shows all its source bars. Joined timed runs use four fixed numbered slots; only measured, completed source bars with expired held cues can refill. While paused or during unmeasured playback, Previous/Next page keys or their assigned pedals turn overlapping windows such as 1–4, 3–6 and 5–8 without changing tempo.

Without a piano input, Practice supports reading, repetition and tempo controls directly. Done defaults to Enter and can be assigned another key or MIDI pedal in Options. After a full loop at that passage and rate, Done toggles a reversible self-reported completion; existing marks can always be withdrawn. A sounding loop finishes before its queued increase. Repeat this speed keeps the rate; Done never selects another passage. During repeat count-in, Done/undo refers to the just-played rate and starts a fresh full count. Self-reports are separate from retained measured/legacy bests and never fabricate played notes.

R carries one display orientation through Library, Reader, Practice and dialogs. An explicit shared display choice wins; before it exists, nonzero library rotation takes precedence, otherwise the first opened score can supply its saved orientation. Raw old rotation fields remain intact. Assigned R/Shift+R actions retain priority, and text entry or shortcut capture protects its input. Rotation and resizing do not restart the current Practice loop.
