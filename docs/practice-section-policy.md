neighboring double, and each qualifying contrast episode before any progress is
recorded. Doubles never generate further originals or longer joins. Exact source
repeats can share genuine attainment, but a double cannot inherit its component
claims. Each included exercise receives one equal share of the completion total;
exclusion removes only that exercise's share and never satisfies prerequisites.

validate old journals. Admission first validates the complete old tree and

recovery envelope. New contrast episodes start without inherited credit. Manual
journals similarly search the current revision first and then accepted old
manual revisions; malformed current data never falls through to another file.

attained progress and the original evidence. Source facts define claim identity.

changing the archived musical source. `transferPracticeEdition` validates the
old edition's journal and transfers only matching complete source exercises to
the new catalog, including each contrast's two actual clips. Source or keyboard
changes refuse transfer. The former journal remains literal recovery evidence;
it does not become a new attainment claim. Canonical archived source facts define
boundaries and equivalence, while the current edition's hands drive practice.
