# Equivalent musical passages share attainment

Completion now follows the actual musical unit rather than its bar-range name. An earned claim for A also counts for A+A when both complete source units are identical. An earned AB run counts for the same ordered AB run elsewhere and for AB+AB. A and B being separately done does not complete a heterogeneous AB run; BA and differently nested heterogeneous joins remain separate.

The planners derive private, temporary equivalence classes from canonical events. They retain note multiplicity, sounding and written pitch, hands and source voices/parts/staves, physical source positions, written values and tie components, rests, local phrase scope, written component topology, complete bar clocks, meter and pickup phase. The actual reference tempo and plan identity bind the lookup. Identical children collapse recursively; heterogeneous pairs retain their order and parent structure. Changed plan clocks, pitches, reference or passage identity disable the old lookup.

The full written range, attacks, repeat/cue clocks, components and existing `pattern` keys are unchanged. Saved measured `best`, self-reported `[passage, pattern]` marks, archives and personal journals are neither migrated nor copied into other keys. A freshly loaded journal or a chooser/library projection derives its own lookup from its real plan. Unplanned targets retain exact-key behavior.

Manual and measured evidence remain separate. `Include manual` filters only self-reported evidence; measured rates can be reused through the same exact musical classes. Completing a loop grants new Done eligibility only to that observed passage and rate. An already earned equivalent claim can be withdrawn from another equivalent passage: undo removes that rate from its equivalent self-report keys, preserves other rates and leaves all measured bests intact. Repeated units never fabricate MIDI contacts or physical assessment for a manual instrument.

Historical measured leaf keys already merged simultaneous same-pitch contacts and do not record the originating passage. Their original key semantics are retained. The new source-derived classes preserve owner multiplicity and do not infer a new equivalence between such unequal musical units. This repair does not invent missing historical provenance.
