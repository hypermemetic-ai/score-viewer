# Optional fingertip reach evidence

`calibration-fingertips-v1.json` is an additive, strict versioned raw archive. It never reads or writes the historical `calibration-pilot-v1.json` or `calibration.json`. Read failure, malformed UTF-8, unsupported schema and invalid readings open read-only, retaining original bytes for lossless export. No automatic migration or reset occurs.

Each append-only reading records its identity, UTC date, instrument, performing hand, adjacent pair, method, primary reference, entered decimal text and numeric value. Hands share one collection; the hand field says which hand performed each reading. Corrections append another reading; revisiting uses the last saved reading for that instrument/pair/method/reference. Existing observations remain in export. Fresh fields are empty. Drafts retain independent values per pair, method and primary reference. Switching hands does not manufacture a second collection or convert a reading.

The protocol identity is `extended-fingertip-reach-v1`, with illustration provenance `accepted-fingertip-illustration-v1`. Jankó permits signed finite decimal percentages no greater than 100, with no lower bound. A negative reading places the fingertip before its local starting line. Direct millimeters record a nonnegative effective extended fingertip reach difference. Conventional piano offers only millimeters. Neither method measures anatomical root-to-tip length; no percentage-to-millimeter conversion or calculator fitting is performed. “Both” means each fingertip reaches its own wall and records 100%; “Equal” records 0 mm. Thumb–index defaults to index as explicitly approved. Other pairs keep a visible editable primary-finger selector.

Save writes before publishing the archive or advancing. A slow write gates editing and duplicate saves; failed writes retain the same page, draft and accepted archive. Left/right navigation retains blank and invalid drafts without saving or completion. Focus breaks or disposal during a write cannot advance or revive the page; the already accepted disk write remains evidence. The host must flush its shared write queue before reopening.

The repository-owned SVG source data and provenance are in `src/calibration-assets/`. These preserve the accepted schematic camera (36° elevation, 5° azimuth), uniform 12.5 tip thickness, common front plane, lower even-parity tips, natural key colors and four unfilled contact-band corners. Thumb rests on ISO 1’s lowest level and index on ISO 4’s lower main level, with a distinct thumb starting landmark. Other pair contacts remain declared visual examples. Horizontal reflection provides a left-hand schematic while labels remain readable. These are presentation dimensions, not a newly validated physical keyboard model; raw evidence is not sent to the calculator as geometry. Extremely negative readings remain valid even when their finger silhouette falls outside the drawing.

Numeric text uses ordinary editing. Command keys handle navigation/save/back; the outer calibration modal must isolate all measurement-page MIDI and digits from effort grading and practice telemetry independently of whether a text key is consumed.
