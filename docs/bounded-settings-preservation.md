# Literal practice settings on migration

Bounded practice reads preserve valid stored Start, Working, Connection Start,
Step, tolerance, offset, count-in length, cooldown, output and per-pattern working
rates exactly. Reading a journal does not act as a speed edit, including when
the old journal lacks a speed or usability revision. Absent optional preferences
receive the current defaults. Invalid values retain the existing refusal path.

Legacy-to-bounded projection and hand/finger edition transfer validate the old
journal without applying its legacy preference migrations to the copied choices.
All original per-pattern rate entries remain available; matching complete ranges
also receive their current catalog keys. Recovery envelopes and edition evidence
retain the literal original journal. Working rates are preferences, not measured
credit; attainment still transfers only through its complete source-range guards.

Target follows the accepted clock authority: an explicit `personalGoal` owns a
chosen target, otherwise Target is a cache of the reference tempo. The migration
does not infer a personal goal from an older cached Target. Explicit speed edits,
goal edits and successful-loop progression retain their existing rounding rules.
Typing a changed speed or Step validates its entered value, then rounds that
field alone. Committing unchanged displayed text retains its original precision.
The explicit legacy planners retain their historical preference normalization.

Regression evidence uses synthetic journals with Step 5, Start 10 and full
Working precision, plus custom tolerance, offset and per-pattern rates. Checks
cover both legacy partitions, bounded reloads with and without a speed revision,
manual record roundtrips, actual calculated-edition storage writes, existing
target authority, failed saves and unchanged raw recovery bytes. No private
operator journal is included. These source checks do not establish native
installation or physical piano acceptance.
